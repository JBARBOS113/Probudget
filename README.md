# 🧪 Cypress + Gherkin Testing Framework

Automated end-to-end (E2E) testing framework using [Cypress](https://www.cypress.io/) with [Gherkin syntax](https://cucumber.io/docs/gherkin/) for behavior-driven development (BDD). Este proyecto está desarrollado en **Node.js** con **JavaScript**.
